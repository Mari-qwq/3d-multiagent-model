# Multiagent Random Walk 3D

Программное средство для моделирования многоагентной системы случайного блуждания в трёхмерном пространстве.

## Описание проекта

Проект посвящён исследованию статистических характеристик взаимодействий между агентами, совершающими случайное блуждание в ограниченной трёхмерной области.

Модель реализует:
- движение агентов в 3D пространстве;
- отражение от границ параллелепипеда;
- вычисление моментов взаимодействия;
- определение длительностей взаимодействий и расхождений;
- статистическую обработку результатов;
- построение графиков распределений и математических ожиданий.

## Используемые технологии

- C++
- Python
- NumPy
- Pandas
- Matplotlib

## Структура проекта

```text
cpp/        - вычислительный модуль
python/     - анализ и построение графиков
data/       - CSV-файлы результатов
results/    - графики и изображения

## Запуск проекта

### Компиляция C++ программы

```bash
g++ MultiAgentSystem3D.cpp -O2 -o simulation
```

### Запуск моделирования

```bash
./simulation
```

После выполнения программы формируются CSV-файлы со статистикой.

## Построение графиков

Установка зависимостей Python:

```bash
pip install -r requirements.txt
```

Запуск анализа:

```bash
python analysis.py
```
